# CO2Calculator
Single page to calculate CO2 emission

## 🌐 Acesso Online
Este projeto está publicado no GitHub Pages: [https://fgiacobe.github.io/CO2Calculator/](https://fgiacobe.github.io/CO2Calculator/)

## 📝 Sobre
Calculadora web para estimar emissões de CO2 de diferentes meios de transporte.

## 🚀 Deployment
O site é automaticamente publicado no GitHub Pages através do GitHub Actions quando mudanças são enviadas para a branch `main`.

### ⚠️ Configuração Necessária
**Se você está vendo erro 404**, é necessário configurar o GitHub Pages no repositório:
1. Vá em **Settings** → **Pages**
2. Em **Build and deployment** → **Source**, selecione **GitHub Actions**
3. Re-execute o workflow ou faça um novo push

📖 **[Guia completo de deployment](DEPLOYMENT.md)** - Instruções detalhadas e troubleshooting
